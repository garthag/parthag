# Legacy editions (kept for reference)

Until November 2026 CONSTRUCT DPR was built as a React/TypeScript PWA on Supabase, with Capacitor (Android) and Electron (Windows) wrappers, a Google Workspace edition and Python/Java clients. All of it was restructured into one C# / .NET 10 solution in the repository root.

Nothing here is built or deployed any more. The Supabase database of the old edition can host the new server: its tables live in the separate schema `cdpr`.
